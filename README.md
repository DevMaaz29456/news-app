News App

Overview

This is a React.js based News Application that provides the latest news headlines from various categories using the NewsAPI. The project is styled with Bootstrap for a responsive and elegant design.

Features

📰 Fetches real-time news using the NewsAPI.

🎨 Styled with Bootstrap for a clean and responsive UI.

🔍 Different categories of news (e.g., Business, Sports, Technology, Entertainment, etc.).

🌍 Covers top headlines from the US.

⚡ Fast and efficient API integration.

Tech Stack

Frontend: React.js, Bootstrap

API: NewsAPI.org

Installation & Setup

1️⃣ Clone the repository:

 git clone https://github.com/DevMaaz29456/news-app.git

2️⃣ Navigate to the project directory:

 cd news-app

3️⃣ Install dependencies:

 npm install

4️⃣ Create a .env file in the root directory and add your NewsAPI key:

VITE_API_KEY=your_api_key_here

5️⃣ Start the development server:

 npm run dev

Usage

Select a category to view the latest news.

Click on Read More to open the full article in a new tab.

Deployment

To build and deploy the app:

 npm run build

Then deploy the dist folder to Vercel, Netlify, or any static hosting service.

API Key Setup

Get your API key from NewsAPI.org

Add it to your .env file as shown above.
